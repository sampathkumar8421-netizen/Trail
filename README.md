# Trail — SaaS Spend & Renewal Management

A purpose-built spend management and contract defense operating system engineered for finance operations teams at 50–200 person companies.

## Documentation
- **Full Product Requirements Document (PRD v2.0)**: See [`PRD.md`](./PRD.md) for complete specifications, Mermaid architecture diagrams, mathematical calculation engines, screen wireframes, and standard operating procedures (SOPs).

## Local Development
```bash
# Install dependencies
npm install

# Start development server on port 5180
npm run dev

# Build production bundle
npm run build
```

## Local Port Allocation
- Trail Spend Dashboard: `http://localhost:5180/`
- Detailing Website: `http://localhost:5174/`
